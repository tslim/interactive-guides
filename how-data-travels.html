Model notes

Messages belong to applications; TCP carries a byte stream in segments, IP carries packets, and links carry frames. A TCP write need not equal one segment or read. Applications must mark message boundaries; UDP preserves datagram boundaries.

A1/A2 label data groups, not TCP message numbers. Maximum transmission units (MTUs) constrain real packet sizes.

4 · Loss & ordering

Arrival ≠ app delivery.

TCP: ordered bytes

Retransmits losses. Later bytes wait behind gaps. Persistent failure can end the connection.

UDP: datagrams

No built-in recovery or ordering. Apps can add both, plus congestion control.

Model notes

QUIC runs over UDP but adds security, recovery, congestion control, and ordered streams. Missing data on one stream need not block another. HTTP/3 uses QUIC; network delay still applies.

A TCP acknowledgment confirms transport receipt—not app processing, saving, or human reading. Those need application-level receipts.

Model notes

All numbered audio chunks are ready to send initially. Chunk 1 is due at 300 ms, then one every 150 ms. These invented deadlines illustrate playout, not a complete live call.

Real media needs security, congestion handling, and jitter buffers. Missing audio may be concealed, recovered, or skipped. Files need every byte; chat needs complete messages and app receipts; calls also need timely data. No transport wins universally.

6 · Chat without refreshing

Ask repeatedly, or stay open?

Packets move data. Messaging patterns decide when to send it.

Polling

Browser asks; server answers. Connections can be reused.

SSE

Server pushes events. Browser replies use separate HTTP requests.

WebSocket

Either side sends on one channel. Messages are not individual packets.

An open channel removes polling, not network delay.

Model notes

Playback advances one story step per beat. Tokens show direction, not speed. Transit and processing are omitted to isolate app waiting.

Classic WebSocket uses TCP: missing earlier bytes can delay later messages. WebSocket adds framing; wss:// adds TLS protection.

A separate HTTP request need not create a new physical connection. All patterns need connection management; reconnecting does not guarantee replay. Long polling—holding a request until news or timeout—is another option.

Keep the layers separate.

Links carry packets. Routers choose hops. Transports shape delivery. Apps decide what matters.
